# 오류 기록

기준: 2026-11-24. v0.1.0을 만들면서, 그리고 그 뒤 모델을 실제로 돌려 보면서 찾은 오류, 고친 방법, 아직 남은 문제, 확인하지 못한 것을 적는다. 설계는 [설계서](SPEC.md)에 있다.

확인한 방법은 세 가지다.

- **시험**: `flutter analyze` 0건, `flutter test` 전체(1,279건, 모델 파일이 있어야 도는 9건은 따로) 통과, 라이선스 검사 통과
- **CI**: 시험 · 서버 SQL · 웹 빌드 · Android 빌드 · Windows 빌드
- **실제 화면**: 웹 빌드를 띄우고 실제 서버(Supabase)에 시험 계정을 만들어 눌러 본 뒤 계정을 지웠다
- **실제 모델**: 모델 파일(Qwen3.5-2B · 4B)을 앱의 런타임에 올려 Linux에서 돌렸다(1.6절)

Android · Windows 앱은 **빌드가 되는 것까지만** 확인했다. 기기에서 실행해 보지는 못했다(4장).

## 2. 남아 있는 문제

| K | **PC 앱에서 Google 로그인을 마쳐도 앱으로 돌아오지 않는다.** 브라우저에 웹 가계부가 열린다 | 서버(Supabase)의 Redirect URLs에 앱 주소(`io.github.kimhershey.gagyebu://login-callback`)가 없어 서버가 웹 주소로 돌려보낸다. 앱과 웹은 실패를 알리지 않는다 | 서버 설정에 앱 주소를 더한다(사용자). 실패를 알리는 수정은 [인계 문서](HANDOFF.md) A |
| L | AI 모델 화면의 모델 줄이 제각각 가운데로 쏠려 보인다 | 보기에만 어색하다 | [인계 문서](HANDOFF.md) B |
| M | PC에서 앱이 모델 서버(`llama-server`)를 스스로 띄우게 했지만 **Windows에서는 돌려 보지 못했다.** 같은 판의 Linux 실행 파일로만 확인했다 | 띄우지 못하면 앱 안의 엔진으로 물러나므로 읽기는 계속 된다 | PC에서 설정 → AI 모델의 "엔진" 카드가 "실행 중"이 되는지 본다. 남은 일은 [인계 문서](HANDOFF.md) C |

설계에서 일부러 정한 한계(충돌은 행 단위, 카드 결제 예정액은 어림, 앱 잠금은 화면만 가림, 브라우저가 저장소를 지울 수 있음)는 [설계서 10장](SPEC.md)에 있다.

## 4. 확인하지 못한 것

코드와 시험은 있지만 실제로 돌려 보지 못했다. 기기나 계정이 있어야 볼 수 있다.

| 무엇 | 왜 못 했나 | 확인하는 방법 |
| --- | --- | --- |
| Android · Windows 앱의 실제 동작 전반 | 여기에는 기기가 없다. CI에서 빌드만 했다 | 릴리스의 APK · 설치 파일을 깔아 입력 → 저장 → 동기화를 해 본다 |
| 기기 안의 모델을 Windows · Android **기기에서** 쓰는 것: 화면에서 내려받기, Windows의 Vulkan 가속, 휴대폰의 속도와 메모리 | 기기가 없다. Linux에서 실제 모델로 돌려 본 것까지가 확인한 범위다 | 앱의 설정 → AI 모델에서 받아 모르는 형식의 문자를 넣어 본다 |
| 이미지 입력의 정확도(Windows) | 시험용으로 그린 그림 두 장만 읽혀 봤다. 실제 은행 앱 화면과 종이 영수증 사진은 재지 않았다 | 은행 앱 캡처와 영수증 사진을 넣어 본다 |
| 앱에서의 Google 로그인 왕복 | Google 계정으로 실제 로그인해야 한다 | Supabase → Authentication → URL Configuration에 `io.github.kimhershey.gagyebu://login-callback`을 더한 뒤 앱에서 로그인한다 |
| 웹에서의 Google 로그인 왕복 | 위와 같다. Google 화면으로 넘어가는 것까지 봤다 | 공개 페이지에서 Google로 로그인한다 |
| 비밀번호를 다시 정하는 메일 | 실제 메일함이 있어야 한다 | "비밀번호를 잊었습니다"로 메일을 받아 링크를 눌러 본다 |
| 두 기기가 5초 안에 맞춰지는지(실시간 신호) | 가짜 서버로만 시험했다 | 두 기기에서 같은 계정으로 열고 한쪽에서 저장한다 |
| 공유로 받은 글(Android) | 기기가 없다 | 문자 앱에서 "공유 → 가계부"를 눌러 본다 |
| iPhone Safari: 키보드가 올라올 때 입력창이 가려지는지, 한글 입력 | iPhone이 없다 | iPhone에서 공개 페이지를 열어 적어 본다 |
| 업데이트 알림 | 올라간 릴리스가 있어야 한다 | 다음 버전을 올린 뒤 옛 버전의 앱을 연다 |
| 백업 · 정리 작업 | 비밀값(`SUPABASE_DB_URL`, `BACKUP_PASSPHRASE`)이 있어야 돈다 | 비밀값을 넣고 Actions에서 "백업"을 손으로 돌린다 |
